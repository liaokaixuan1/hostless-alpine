Alpine on Hostless

darkhttpd · read-only rootfs · single replica · 0.1 vCPU / 256 MiB

base imagealpine:3.21
web serverdarkhttpd (single static binary)
pid 1entrypoint.sh → exec darkhttpd
portfrom $PORT (Hostless-injected)
bind0.0.0.0
filesystemread-only root；可写仅 /tmp /root /app/.cache
health checktcp probe, 10s interval
image size~5 MB（alpine + darkhttpd + tzdata）

结论：Hostless 能用 Alpine 做基础镜像。Docker 构建路径（build.system: docker）完整可用，构建阶段免费、不计入免费池。

踩到的第一个坑值得记下来：Alpine 的 busybox 不带 httpd applet，busybox-extras 也不提供它。写 busybox httpd -f -p $PORT 会在运行时直接报 httpd: applet not found，容器反复重启、部署状态变成 DEPLOYMENT_FAILED / FAILED_TO_START。换成 darkhttpd 即可。

第二个坑：根文件系统只读。任何往 /var、/run、应用目录写文件的服务端（nginx 写 pid、官方镜像写 config.toml）都会 EROFS 退出。darkhttpd 不写盘，所以合适。
